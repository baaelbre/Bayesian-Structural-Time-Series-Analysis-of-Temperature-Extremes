# BUCEX 2.2.0 release notes

## What is new

Version 2.2.0 closes three publication-blocking gaps in 2.1.x:

1. GEV structural SSVS can now be run with exact-invariant PGAS rather than
   only an approximate Laplace state update.
2. FS backward covariance handling is stable for long records, singular
   transitions, and innovation scales close to zero.
3. Forecast validation is end to end: expanding-window leave-future-out
   refits, analytic log predictive scores, CRPS/tail scores, and held-out PIT
   diagnostics use one API for univariate and factor models.

It also corrects the static dummy-seasonal FS regression design. Because this
changes the seasonal likelihood calculation, rerun every 2.1.x FS analysis
that included `DummySeasonal`, even if its old MCMC diagnostics looked good.

## Exact PGAS--SSVS

Conditional on a PGAS state path, each zero/fixed/dynamic model has a
different active FS coefficient vector. The v2.2 update:

1. constructs a deterministic Gaussian pseudo-posterior for every model;
2. mixes its approximate model weights with a uniform full-support proposal;
3. proposes a model and its active coefficients jointly;
4. accepts/rejects with the exact GEV likelihood, normalized model/slab priors,
   and forward/reverse proposal densities;
5. refreshes active coefficients by exact elliptical-slice sampling.

Laplace therefore affects efficiency, not the PGAS target. Inspect
`fit.metadata["model_selection_exact"]`, the model-MH acceptance rates,
component probabilities, transition summaries, and ordinary chain/particle
diagnostics. Exactness does not guarantee useful mixing.

## Joseph-form FS smoothing

The former backward covariance expression `C - J R J'` could subtract nearly
equal matrices. The new expression `(I-JG) C (I-JG)' + JQJ'` is equivalent in
exact arithmetic and positive-semidefinite by construction. A symmetric solve
or Moore--Penrose inverse handles legitimate singular predicted covariances;
the final sampler still rejects materially indefinite inputs. No process
variance is injected into deterministic directions.

## Static component semantics

Under FS SSVS:

- fixed level = static `alpha0`, exactly zero level innovation;
- fixed trend = static `beta0`, exactly zero slope innovation;
- fixed season = static initial-season vector, exactly zero seasonal
  innovation;
- zero trend/season additionally removes its static coefficient;
- dynamic adds the corresponding signed innovation-scale coefficient.

The seasonal coefficient design is now generated by powers of the same
sum-to-zero rotation used in state reconstruction, and an algebraic test
requires the regression predictor and reconstructed predictor to agree to
machine precision.

## Compatibility

The model grammar, `fit()`, `FitResult`, archive schema, plotting names, and
prior profiles are source compatible with 2.1.5. Numerical posterior results
with seasonal FS models are intentionally not backward compatible because of
the corrected design. GEV SSVS scripts that selected Laplace explicitly remain
approximate; switch to `engine="pgas"` for publication inference.

See Examples 11--13 and `docs/PREDICTIVE_VALIDATION.md` for the new workflows.
